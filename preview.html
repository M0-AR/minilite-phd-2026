CEO summary — 5 sentences

  1. Every phone and browser runs SQLite; minilite rebuilds its core so anyone can see how it works.
  2. One million users in one file; user 777777 found in 3 pages (0.4 ms at 100k, 3.5 ms at 1M Python).
  3. Email without index scans 25,718 pages (3.2 s); with index 7 pages (3.8 ms) — planner prints its choice.
  4. Kill mid-write: without journal corrupt, with journal auto-heals on reopen — both demonstrated.
  5. One-command Docker reproduce, layer-by-layer teaching, browser quiz, real SQLite + live BTC comparison.
